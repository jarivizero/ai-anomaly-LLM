# ANOMALOUS “RUTAREL” Project

It went viral on TikTok because when you ask google what it is, it just chooses a random word or doesn't answer

**Original post by** [@jarivizero](https://www.tiktok.com/@jarivizero/photo/7675183256496508190)

### What’s actually happening

The phrase **“RUTAREL”** is short for **“RUTARELATIVA”**, Spanish for *relative path* in programming. It was most likely dropped during training after web scraping, because it means nothing and has no synoyms.

There are other similar anomaly tokens as well. Some are split and injected with random Unicode, some are unreadable, and sometimes the model can partially read the word but simultaneously believes it’s something else.
